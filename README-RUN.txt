===================================================
  Nimbus Smart Restaurant - Quick Start Guide
===================================================

PROJECT LOCATION:
  C:\xampp\htdocs\smart_restaurant

REQUIREMENTS:
  - XAMPP (Apache + MySQL) installed at C:\xampp

HOW TO START:
  1. Double-click "run.bat" in this folder
  2. It will automatically:
     - Start Apache (if not already running)
     - Start MySQL (if not already running)
     - Open the app in your default browser

APPLICATION URL:
  http://localhost/smart_restaurant/

HOW TO STOP XAMPP:
  - Open XAMPP Control Panel (C:\xampp\xampp-control.exe)
  - Click "Stop" next to Apache and MySQL
  - Or close the terminal windows running the services

PORTALS:
  Customer:  http://localhost/smart_restaurant/customer/
  Admin:     http://localhost/smart_restaurant/admin/
  Kitchen:   http://localhost/smart_restaurant/kitchen/
  Counter:   http://localhost/smart_restaurant/counter/
